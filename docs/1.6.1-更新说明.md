# 万象 v1.6.1

## 修复

- 修复「检测更新」在 GitHub API 返回 403/429 时直接失败的问题：现在会回退到 `releases/latest` 的 302 跳转，从 Location 解析版本号，不占用 API 配额。
- 403/429 时仍能判断是否有新版本；更新说明拿不到时提示「请打开下载页查看」。
- 检测失败时提供「打开发布页」按钮，可直接跳到浏览器；非限流的 500 等错误不再回退，避免掩盖真实故障。

## 更新

- 检测更新失败提示会带上具体状态码，便于判断是限流还是网络问题。
- 新增 3 项测试：403 回退、429 无版本号报错、500 不回退；全量 241 项通过。
