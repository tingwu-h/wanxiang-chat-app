# 万象 v1.3.2

本版改进聊天页的阅读和操作体验。

- **自然淡出**：顶部和底部改为连续渐变，去除分段实时模糊，减少文字出现断层的感觉。
- **菜单更简洁**：新建对话保留在顶部独立按钮；右上角更多菜单改为“导出聊天文字”和“清空当前对话”。空会话不能导出。
- **导出当前会话**：可将当前会话的消息、时间和附件名称保存为 TXT；不会包含 API Key、图片文件或本机附件路径。设置页仍可导出全部历史 JSON。
- **流畅度优化**：流式回复只刷新消息区域，已完成消息的 Markdown 保留解析结果；减轻悬浮控件阴影，并减少重复布局与重绘。

Android 版本 `1.3.2`，构建号 `18`；Dart 工程版本 `1.3.2+18`。包名和原签名保持不变，签名文件仍在原位置。
