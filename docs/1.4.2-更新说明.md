# 万象 v1.4.2

本版把「思考 / 联网」两个开关下移到输入框底部，改成带文字的胶囊按钮；
并修复「问日期只能说无法确定」。

## 1. 开关下移，改成胶囊

```
┌────────────────────────────────┐
│ [＋][ 输入框 ][发送]             │
│ [deepseek-flash]    [思考] [联网] │
└────────────────────────────────┘
```

- **位置**：从输入行移到模型选择器那一行，模型靠左、两个开关靠右。
  输入行只剩「加附件 / 输入 / 发送」，恢复干净。
- **形态**：与模型选择器同一种 `StadiumBorder` 胶囊，不是孤零零的图标。
- **文字**：`思考` / `联网`，不用猜图标含义。
- **状态**：开启是 `primaryContainer` 底色 + 主色文字；关闭只有描边。
  160ms 颜色渐变，不做弹跳。
- **联网图标**：回到矢量图（Material `travel_explore`），任意屏幕密度都清晰。

### 删掉了位图

之前用的 26×26 PNG 在 18dp 下必然发虚，这就是「丑」的根源。
本版删除该资源，全项目**不再有任何位图图标依赖**。

### `思考` 胶囊

仅当前服务商是 DeepSeek 时出现（这是 DeepSeek 专有参数，
对其它厂商显示会让人误以为能控制）。与「设置 → 模型行为」共用同一字段。

## 2. 修复：模型无法回答「今天几号」

**原因**：应用从来没有把当前时间告诉模型。模型的知识有截止时间，
本身不知道今天是哪一天，问日期只能回答「无法确定当前日期」。

**修复**：每次发送时自动在系统提示词最前面注入一行：

```
当前时间是 2026-11-06 22:51（星期五，设备本地时间）。
涉及日期、星期、时间的问题请以此为准，直接回答，不要声称无法确定当前日期。
```

- 默认**开启**，可在「设置 → 模型行为 → 自动告知当前时间」关闭。
- 只注入这一行，**不会覆盖**你自己写的提示词。
- 联网关闭时额外提示：实时信息要说明需要开启联网，不要含糊其辞。
