# 万象 v1.4.0

本版新增四项能力，并统一了开关行为。

## 1. 直接拍照

附件菜单新增「拍照」，可直接调起系统相机拍摄并发送。
拍完仍走原有的裁剪、压缩流程。

- 不需要额外的相机权限（使用系统相机）。
- 取消拍照不会报错。

## 2. 联网搜索（可开关）

接入 DeepSeek 官方 Search / Fetch 接口，让模型能依据实时网页回答。

- **搜索与对话模型解耦**：即使当前用的是 OpenAI、Kimi、Qwen 等模型，联网依然可用。
- **开关位置**：输入栏地球图标（快捷）＋ 设置 → 联网搜索（详细）。两处联动，改一处另一处同步。
- **前提**：需要 DeepSeek API Key（可单独填，也可复用 DeepSeek 服务商的 Key）。
- **可调项**：结果条数、是否抓取正文、是否显示来源链接。
- 回答下方会列出来源，点击用浏览器打开。
- 搜索失败时**降级为无联网回答**，不会让整条回答失败。

> 计费说明：官方按成功请求计费，约 0.75 美元 / 千次。设置页已写明。
> 隐私说明：使用联网时，你的问题会发送给 DeepSeek 搜索服务。

## 3. 每会话独立提示词

系统提示词不再全局统一。

- 会话右上角菜单 →「本会话提示词」，可单独设置。
- 留空则沿用设置页的「默认提示词」，老用户配置不会丢。
- 有自定义提示词的会话会在菜单里显示「已单独设置」。

## 4. 思考模式与推理强度

对齐 DeepSeek 官方最新参数。

- 新增**思考模式开关**（官方默认开启）与**推理强度**（low / high / max）。
- 简单问题可关闭思考，更快更省。
- **思考模式下温度设置不生效**（官方明确），此时温度滑块会置灰并说明，避免误以为滑块坏了。

## 5. 其它调整

- **模型清单对齐官方**：移除 `deepseek-chat` / `deepseek-reasoner`（官方文档已不再列出，选中可能报错）。需要的话仍可在设置里用「自定义模型名」填回。
- **图片细节档位**：可选「低（更快更省）」，官方说明会缩到 512×512。
- Anthropic 协议的 `max_tokens` 由 4096 提升到 8192，减少长回答被截断。

## 开关有效性

本版所有新增开关都按同一标准验证：**能选 / 能存 / 真正生效**。
其中「真正生效」断言的是实际请求内容，而不是界面状态，例如：

- 联网关闭时不产生任何搜索请求；
- 思考关闭时请求体带 `thinking.type=disabled`；
- 思考开启时不发送 `temperature`；
- 图片档位为低时写入 `detail: low`。

新增 28 项针对性测试；全量 139 项通过，静态分析无问题。
