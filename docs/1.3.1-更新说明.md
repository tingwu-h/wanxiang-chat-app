# 万象 v1.3.1

这次更新将聊天页调整为更接近现代移动聊天应用的悬浮布局，并同步更新发布资料。

- **顶部操作悬浮**：隐藏会话名称，历史、编辑和更多操作独立放在顶部圆角悬浮按钮中。
- **底部输入悬浮**：输入框和当前模型选择保持在同一个圆角窗口中，输入区增高时消息列表自动避让。
- **上下边缘淡出**：消息接近顶部或底部悬浮控件时使用渐变和轻微模糊，滚动查看历史更自然。
- **背景保持连续**：消息、输入框和边缘遮罩共享聊天背景，自定义背景不会在上下出现突兀的纯黑块。
- **发布资料同步**：中英文 README、横幅和界面截图更新为当前 1.3.1 布局。

Android 版本 `1.3.1`，构建号 `17`；Dart 工程版本 `1.3.1+17`。沿用原包名和签名，签名文件保持原位置。
