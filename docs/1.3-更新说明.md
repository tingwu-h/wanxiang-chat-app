# 万象 v1.3

这次更新集中修整启动画面和聊天细节，让首屏、消息气泡、模型选择和设置面板更统一。

- **启动图无白边**：清理深色启动背景下可见的图标外轮廓残留，保留 Logo 内部高光与透明背景。
- **空状态更简洁**：新对话不再显示突兀的应用图标，改为“万象聚合，模型无界”。
- **消息显示更紧凑**：用户消息隐藏重复的角色标签和时间空行，输入内容与气泡更接近常见聊天布局。
- **模型选择更轻量**：弹窗默认只展示约两个模型卡片，继续支持上下滑动和独立卡片选择。
- **聊天区域更连贯**：输入框不再带一整块独立底色，与消息区域共享背景。
- **设置面板统一**：语言选择面板使用带外边距的四角圆角容器，避免底部方角和选项覆盖。

Android 版本 `1.3`，构建号 `16`；Dart 工程版本 `1.3.0+16`。沿用原包名和签名，签名文件保持原位置。
