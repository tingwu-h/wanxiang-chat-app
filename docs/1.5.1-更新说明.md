# 万象 v1.5.1

## 更新

- 新增「拒答自动重试」：模型一开口就拒答时，自动用预填充重试一次；默认开启，可在设置 → 模型行为里关闭。
- 新增「始终预填充」与预填充开头文本，默认 `好的，以下是完整实现：`；正常聊天默认不预填充。
- 支持拒答后切换备用服务商（需已保存该服务商的 Key），最多尝试 3 次：正常 → 预填充 → 备用服务商。
- 预填充按协议生效：DeepSeek 带 `prefix: true`，OpenAI 兼容与 Anthropic 追加 assistant 消息；Responses 与 Gemini 自动跳过。
- 重试前会清空上一次的正文与思考过程，不会把两次回答叠在一起。
