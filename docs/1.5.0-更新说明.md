# 万象 v1.5.0

> 本版为替换构建：版本名仍为 1.5.0，Android 构建号 29。

## 更新

- 内置「破甲」插件：随应用提供，默认启用，可在设置 → 对话设置 → 指令插件里关闭。
- 内置项不可编辑、不可删除，只能开关、查看全文、复制为自定义（副本独立）。
- 内置插件恒排在最前，其后才是自定义插件、时间行、用户提示词与检索资料。
- 新增「指令插件」：设置 → 对话设置 → 指令插件，可新建、编辑、排序、启停；支持从文本文件导入、导出为文件。
- 两种生效模式：前置注入（默认，插件排在最前）；覆盖应用注入的说明（去掉时间行与检索引导语，但保留检索资料本体）。
- 聊天页更多菜单新增「本会话指令插件」，可单独指定当前会话启用哪些插件，或跟随全局。
- 新增「预览最终提示词」，按当前设置展示实际发送的 system prompt。
- 插件正文支持 `{{date}}`、`{{time}}`、`{{model}}` 变量；单条上限 4000 字，合计上限 8000 字。
- 插件只在请求时拼接，不写入聊天记录，也不会出现在导出的聊天文字里。
