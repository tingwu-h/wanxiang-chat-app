# 万象长期宣传海报

主标语：万象聚合，模型无界。

辅助文案：让每个想法，都有回响。把常用的 AI 放在一起，让对话更自在。

设计要求：沿用项目所有者提供的 Logo；深蓝底与宽范围、低对比的蓝紫渐变；清晰的中文排版；不含版本号、日期、服务商数量、具体模型列表或可能过时的 UI 截图。右下角仅保留纯白方框，供后续添加二维码，当前不是可扫描二维码。

文件：

- `wanxiang-poster-portrait.png` / `.jpg`：1440 × 1920 竖版。
- `wanxiang-poster-landscape.png` / `.jpg`：1920 × 1080 横版。
- `*-preview.jpg`：缩小预览，不用于替代原图。

二维码区域采用左上角坐标和宽高：竖版 `(1162, 1714, 168, 168)`；横版 `(1662, 839, 148, 148)`。嵌入二维码时保留码本身所需的白色静区。

制作方式：原品牌位图合成 + Pillow 中文字体精确排版，没有使用内置生图工具或图像 API；文案和布局参数在 `tools/create_poster.py`。可在具备 Pillow、NumPy 及 Windows 微软雅黑字体的环境运行 `python tools/create_poster.py` 重新生成。品牌原资源未修改。
