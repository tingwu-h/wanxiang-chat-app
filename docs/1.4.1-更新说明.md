# 万象 v1.4.1

本版修复「问日期只能说无法确定」，并把「思考 / 联网」两个开关下移到输入框底部，换成带文字的胶囊按钮。

## 1. 修复：模型无法回答「今天几号」

**原因**：应用从来没有把当前时间告诉模型。模型的知识有截止时间，本身不知道今天是哪一天，所以问日期只能回答「无法确定当前日期」——这不是模型不自信，是缺了必要信息。

**修复**：每次发送时自动在系统提示词最前面注入一行：

```
当前时间是 2026-11-06 22:51（星期五，设备本地时间）。
涉及日期、星期、时间的问题请以此为准，直接回答，不要声称无法确定当前日期。
```

- 默认**开启**，可在「设置 → 模型行为 → 自动告知当前时间」关闭。
- 只注入这一行，**不会覆盖**你自己写的提示词（全局默认或每会话提示词都保留）。
- 联网关闭时额外提示：涉及实时信息要明确说明需要开启联网，不要含糊其辞。

## 2. 联网与深度思考移到输入栏下方

之前联网图标挤在输入行里，而且用的是 26×26 位图，放大后发虚。

现在两个开关统一下移，和模型选择器同一行：

```
┌────────────────────────────────┐
│ [＋][ 输入框 ][发送]             │
│ [deepseek-flash]    [思考] [联网] │
└────────────────────────────────┘
```

- **胶囊样式**：与模型选择器同一形状语言（StadiumBorder），不是孤零零的图标
- **都带文字**：`思考` / `联网`，不用猜图标含义
- **联网图标回到矢量**：使用 Material 的 `travel_explore`（1.4.0 用的就是它），任意屏幕密度都清晰，不再发虚
- **状态靠颜色**：开启是 primaryContainer 底色 + 主色文字，关闭只有描边

### `思考` 胶囊

仅当前服务商是 DeepSeek 时出现（DeepSeek 专有参数）。点击即切换，与
「设置 → 模型行为」里的开关是同一个字段，改一处另一处同步。
