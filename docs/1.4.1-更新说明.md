# 万象 v1.4.1

本版修复「问日期只能说无法确定」，重做联网图标，并把深度思考开关放到手边。

## 1. 修复：模型无法回答「今天几号」

**原因**：应用从来没有把当前时间告诉模型。模型的知识有截止时间，本身不知道今天是哪一天，所以问日期只能回答「无法确定当前日期」——这不是模型不自信，是缺了必要信息。

**修复**：每次发送时自动在系统提示词最前面注入一行：

```
当前时间是 2026-11-06 22:51（星期五，设备本地时间）。
涉及日期、星期、时间的问题请以此为准，直接回答，不要声称无法确定当前日期。
```

- 默认**开启**，可在「设置 → 模型行为 → 自动告知当前时间」关闭。
- 只注入这一行，**不会覆盖**你自己写的提示词（全局默认或每会话提示词都保留）。
- 联网关闭时额外提示：涉及实时信息要明确说明需要开启联网，不要含糊其辞。

## 2. 联网开关换用项目图标

输入栏的联网开关改用项目自带图标（`assets/branding/search_icon.png`），开启时不透明、关闭时半透明，状态一眼可见。

> 说明：源图分辨率是 26×26，按 18dp 小尺寸渲染并开启中等插值。若想让它在高密度屏上更锐利，可以提供 96×96 或更大的版本替换同名文件。

## 3. 深度思考开关移到输入栏

之前思考模式被放在「联网搜索」子页里，和联网毫无关系，很难找——这是设计失误。

现在：

| 位置 | 说明 |
|---|---|
| **输入栏** | 联网图标旁新增大脑图标，一键开关深度思考 |
| **设置 → 模型行为** | 独立的设置页，含思考开关、推理强度、图片档位、时间注入 |
| **显示条件** | 仅在当前服务商是 DeepSeek 时出现（这是 DeepSeek 专有参数，对其它厂商无效） |

两处共用同一字段，改一处另一处立刻同步。
