# 万象 v1.6.0

## 更新

- 新增「创建文档」：输入栏「＋」→ 创建文档，可选 Word / Excel / PPT；填写主题或使用当前对话，App 让 DeepSeek 返回结构化 JSON，在本地组装文件并通过系统保存框写入。
- Word 支持标题、段落、项目符号与表格；Excel 支持多工作表、表头与数字；PPT 基于内置模板生成标题 + 要点的页面。
- 模型选择菜单与设置页会显示「支持生成文件 / 暂不支持生成文件」，当前仅 DeepSeek 适配，其他服务商入口置灰。
- 设置 → 关于万象新增「检测更新」：读取 GitHub 最新 Release，比较版本，展示更新说明并可跳转下载页。
- 单文件上限 10 MB；生成全部在本地完成，不上传到第三方转换服务。

## 修复

- 修复指令插件页「新建插件」按钮被全局最小宽度撑成空白胶囊、并把「导入插件」挤出屏幕的问题：按钮改为 Wrap 布局，并取消无限最小宽度。
