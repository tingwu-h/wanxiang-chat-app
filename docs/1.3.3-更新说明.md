# 万象 v1.3.3

本版改进聊天气泡的文字选取与背景可读性。

- **长按可选取文本**：长按气泡即可选中任意文字（此前只能整条复制）。选中后弹出的菜单提供：
  - **复制当前选中文本**：只复制选中的那一段。
  - **追问**：把选中的文字引用到聊天输入框，接着就这段内容继续提问。
  - **复制全文**：一次复制整条消息。
- **引用格式**：追问时选中的文字会以引用块（`>`）拼在问题前面发送，模型能分清哪段是被追问的原文。输入框上方会显示引用条，点 ✕ 可取消。
- **气泡改为磨砂玻璃**：气泡半透明并带背景模糊，消息再多也不会把自定义聊天背景完全盖住。
- **气泡不透明度可调**：设置 → 外观设置 → 气泡不透明度，范围 30%~100%，默认 80%。仅在设置了自定义背景颜色或背景图片后显示。
- **性能取舍**：没有设置自定义背景时不启用模糊层，避免白白增加每帧的 GPU 开销；流式回复期间保持轻量渲染。

Android 版本 `1.3.3`，构建号 `19`；Dart 工程版本 `1.3.3+19`。包名和原签名保持不变，签名文件仍在原位置。
