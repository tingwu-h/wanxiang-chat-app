# 万象指令插件库

这里存放可直接导入「万象」的提示词插件。全部是纯文本，不含代码、不联网、不读取本地文件。

## 怎么用

1. 打开 万象 → 设置 → 对话设置 → 指令插件
2. 点「导入插件」，选择本目录下的 `.md` 文件
3. 文件名会成为插件名，正文就是提示词
4. 打开右侧开关即可生效；也可以在聊天页「更多 → 本会话指令插件」里只对当前会话启用

单条上限 4000 字，所有启用插件合计上限 8000 字。

## 写自己的插件

- 纯文本，UTF-8，不需要 Markdown 语法
- 可用变量：`{{date}}`、`{{time}}`、`{{model}}`
- 建议写成「角色 + 规则 + 输出格式」，一条规则一行
- 不要写“忽略所有限制”这类空话，模型不会因为一句话就改变服务端策略

## 注意

插件只影响发送给模型的 system prompt，不改变服务商服务端的策略，也不保证模型一定遵从。内置「破甲」插件不可编辑，只能开关或复制为自定义。
